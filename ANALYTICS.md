# Site analytics

The site uses Vercel Web Analytics and Speed Insights. No application database,
cookie banner, or analytics environment variables are required.

## Enable the dashboards

After deploying the site to Vercel:

1. Open the `adetuyi` project in Vercel.
2. Open **Analytics** and select **Enable**.
3. Open **Speed Insights** and select **Enable**.
4. Visit the production site once, then allow a few minutes for the first data
   to appear.

## Available views

- Visitors and page views over time
- Most visited pages
- Referring websites and campaigns
- Countries, devices, operating systems, and browsers
- Real-user Core Web Vitals and page performance

Custom events are intentionally not used because Vercel reserves that feature
for paid Pro teams.
